Attributions & Credits

This project was developed for the WDD 330 Final Project by Simeon Obianwa. Below are the credits for the resources, APIs, and technologies utilized to build this application.

Technologies

  • HTML5, CSS3, & Vanilla JavaScript: Built entirely without front-end frameworks to demonstrate core web development competencies.
  • ES Modules: JavaScript architecture utilizing modular classes and imports.
  • Web Storage API: Utilizing localStorage to manage user preferences, visit counts, and favorite locations.

Third-Party APIs

  • REST Countries API: Used to fetch and display national statistics for Nigeria.
  • Wikipedia Action API: Used to retrieve dynamic summaries for each tourist spot.
  • Open-Meteo API: Used to provide real-time weather data based on the geographic coordinates of each location.

Media & Assets

  • Images: Tourist spot images were sourced from Wikimedia Commons and are used under their respective public domain or Creative Commons licenses.
  • Typography: 'Poppins' font family provided by Google Fonts.
  • Icons: Social media SVG icons provided by Simple Icons and served via the jsDelivr CDN.

Data

  • JSON Database: Custom-built spots.json file containing metadata, geographical coordinates, and categorization for 36 unique Nigerian tourist destinations, hotels, and services.
